# Civ6 2K Online Fix 1.2.1

- **自动适配游戏更新**：EXE 更新后，工具会先检查是否仍兼容现有修复方法，通过检查后自动尝试修复，再确认 2K 状态，不再仅因哈希变化就提示不支持。
- **新版实测**：Windows Steam 版《文明 VI》1.0.12.74 的 DX11、DX12 已完成修复验证，保留对旧构建的支持。
- **结果更明确**：无法确认兼容，或尝试后未观察到修复效果时，会提示当前构建暂不支持；读取不完整、已经拦截但仍未就绪的情况，继续提供超时诊断和完整反馈文件。

已有 1.2 的用户，打开工具或点“检查更新”，在提示中选择“是”即可自动下载、校验并升级到 1.2.1，配置和反馈文件保留。首次使用或从更早版本升级，请下载 `Civ6_2K_Online_Fix_1.2.1.zip`，解压到新文件夹运行。

后续游戏更新仍需通过兼容检查；较大的结构改动可能需要更新工具。
