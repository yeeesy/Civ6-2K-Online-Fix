# 源码 Review 与诊断改进记录

## 范围与结论

本次手工 Review 以公开 `v1.0.0` 源码为基线，覆盖进程/文件/运行库身份、远程读取、IAT 发布与撤销、Guard 生命周期、会话状态机、GUI/共享报告、Steam 元数据解析及构建/CI/打包边界。改动集中于读取可靠性、停止请求优先级与诊断可观测性。

发现并修正以下代码缺陷；没有把它们直接归因为外部用户报告的 SQLite 相关超时，也没有据此声称整个项目不存在其他漏洞。本机 DX12 已完成一次新版修复和诊断验证，其他环境及取消路径仍需验证。

## 已确认问题与证据

| 问题 | 影响 | 修正与回归证据 |
| --- | --- | --- |
| 锁向量 begin/end 任一读取失败会跳过可选布局探测，并继续校验成功路径 | 必要读取不确定时可能仍进入写入路径，违背失败关闭要求；不是已证明可利用的攻击 | `ReadLockVector` 区分读取失败、合法空向量和非法布局；仅成功读取的零/零向量允许省略后续探测。测试覆盖首字段失败、尾字段失败、空向量和半初始化向量 |
| 安装阶段通知后或就绪采样通知中收到的取消请求可能被忽略到下一轮，但本轮已终结 | 用户点击停止后可能仍安装保护，或被成功/超时结果盖过，未进入用户请求的撤销路径 | 原有接口下新增测试先复现失败；安装调用前和终态判定前重查请求，进入已有所有权清理路径。覆盖安装边界、成功边界和到期边界 |
| 将所有 `>= 4` 状态视为就绪 | 未验证状态（例如 5 或整数上界）可能被误报为在线 | 只接受已验证的 `4/4`；新增负向测试在修改前失败、修改后通过 |
| 计数器可读被当作整个样本可读；部分读可能污染输出；失败样本被丢弃并继续显示旧值 | 无法区分对象未创建、读失败、旧值；计数器失败还会掩盖可用的服务状态信息 | 精确读取先写临时变量，仅完整成功才赋值；三个字段独立采集。新增旧值与报告测试先失败后通过，并覆盖短读、指针/数值失败、溢出和计数器独立失败 |
| 重试启动时只更新控件，短暂保留上一轮共享状态 | 点击复制可能拿到上一轮诊断 | 新一轮开始清空旧消息并应用新的 Preparing 快照；未做交互式 GUI 自动测试 |
| 剪贴板写入失败时仍显示“已复制” | 用户可能粘贴旧内容、误以为已提供本轮报告 | 写入函数返回实际成功结果，失败反馈测试先失败后通过；分配内存失败不会先清空剪贴板。未做操作系统剪贴板争用的交互验证 |

测试名及实现见 `tests/Civ6FixCoreTests.cpp`、`src/DiagnosticData.h`、`src/FixSession.cpp`、`src/Win32FixPlatform.cpp`。诊断字段和分类语义见 [DIAGNOSTICS.md](DIAGNOSTICS.md)。

## 保持的边界

- Profile 的哈希、RVA、写入许可和 Guard 51 字节机器码未改动。
- 未放宽目标进程/文件身份、System32 运行库精确导出与执行映像要求。
- IAT compare-before-write、写入后回读、页面保护恢复、所有权判断和存活进程不热释放策略未改动。
- 必须读取成功才能使用数值；读失败不会制造就绪状态或跳过必要校验。
- 共享报告仅使用类型化白名单字段；测试对全部结果分支注入虚构路径、账号标记、PID、地址和任意 Profile 文本，确认不会出现在报告中。
- 日志、SQLite、账号数据和真实游戏文件不属于共享报告采集范围。

## 仍需明确的限制

- IAT 比较、写入和回读是分开的跨进程操作，并非远程原子 compare-and-swap；本次没有消除外部并发写入的剩余风险，也没有以诊断升级改变保护机制。
- 服务状态为顺序采样，时间线不能看见两次轮询之间的全部变化；未取得完整状态枚举含义，不能用数值推断数据库/网络阶段。
- 取消仍在既有安全边界检查；已开始的同步运行时校验不被强行中断。
- 原始本地日志仍可能包含隐私；改进的是共享报告，不是将原始日志变为可公开资料。
- 公开反馈目前不足以复现 SQLite 相关故障；需要新报告及游戏内实际状态。不能称该外部故障已经修复。

## 验证与发布前事项

使用 `build.ps1 -Analyze` 执行警告即错误构建、C++ 回归及版本/打包/CI 策略测试，并执行 `--self-test` 纯离线自检。测试仅使用合成样本，不包含第三方用户日志或数据库。

诊断开发构建：116 项断言通过（基线 89 项，新增 27 项），MSVC `/analyze` 构建通过，离线自检退出码为 0，EXE SHA-256 与构建清单一致，`git diff --check` 通过。已知个人标识/凭据模式检查零命中；这不是穷尽式秘密扫描。原有 `1.0.0` 归档保持不变。已完成本机 DX12 的一次修复与增强诊断验证；新版本发布仍需独立检查下载包和远端 CI。

`1.1.0` 公开增强诊断，方便外部用户提供可定位的反馈。SQLite 相关超时尚待新报告确认；取消路径和更多环境仍需持续验证。旧版已完成的游戏验证不能自动证明本次改动已经通过。
