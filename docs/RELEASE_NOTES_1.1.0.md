# Civ6 2K Online Fix 1.1.0

这次更新修复了状态读取和停止操作中的几个问题，也把“复制脱敏诊断”从最后三个数字扩展为一份可追踪启动过程的报告。遇到“持续检查 2K 状态，最后超时”的用户，请升级后提供新版报告。

## 更新内容

- 分别记录拦截计数、Discovery、SSO 的读取情况：末次值、读取是否成功、失败次数、最近一次有效值距结束多久，以及相关 Win32 错误码。这样能区分“状态一直未就绪”和“状态没读到”。
- 增加相对时间线，显示服务对象何时出现、状态何时变化、首次拦截发生在何时；记录等待游戏、运行时校验和监控各用了多久。时间线有固定上限，省略的变化会标明数量。
- 超时报告增加六类观察结果，例如没有取得样本、计数器不可读、服务对象尚未创建、已拦截但未就绪。分类方便确定下一步查什么，不代替游戏内实际状态。
- 修复部分内存读取失败后仍显示旧状态的问题；锁向量读取不确定时停止安装保护；只把已验证的 `4/4` 状态判断为就绪。
- 修复点击停止后可能仍继续安装或直接给出成功/超时结果的问题；重新检测时清除上一轮摘要；复制到剪贴板失败时不再显示“已复制”。

## 下载与反馈

下载 `Civ6_2K_Online_Fix_1.1.0.zip` 和对应的 `.zip.sha256`，核对校验值并解压。完全退出游戏和旧版工具后，运行新 EXE；等工具进入监听，再从 Steam 启动文明 VI，选择 DX11 或 DX12。

如遇问题，请在关闭工具窗口前点击“复制脱敏诊断”，发送**完整内容**，并说明游戏内实际在线状态、是否进入主菜单、能否进入联机，以及问题是每次出现还是偶发。新版报告会显示 `诊断格式：2`。

不要为测试删除 SQLite，也不要公开原始 JSONL、数据库、账号信息或完整本机路径。已有 `1.0.0` 下载包仍保留供对比；本版 EXE 未做商业代码签名，请勿因此关闭安全软件。

完整使用和诊断说明见 [README](https://github.com/yeeesy/Civ6-2K-Online-Fix#readme) 与 [诊断指南](https://github.com/yeeesy/Civ6-2K-Online-Fix/blob/main/docs/DIAGNOSTICS.md)。
