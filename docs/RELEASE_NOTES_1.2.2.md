# Civ6 2K Online Fix 1.2.2

- **完整发行文件更新**：工具内升级现在会同步更新主程序、说明文档、源码、构建信息和校验清单，避免目录内新旧版本混杂。
- **保留个人文件**：用户 INI、日志、反馈和自行添加的文件保留。遇到用户改动过的发行文件或路径冲突时，停止更新并保留原文件。
- **失败整体回退**：安装途中、自检或启动确认失败时，撤销本次发行文件的替换、新增和删除；恢复不完整时保留备份，供下次启动继续恢复。
- **旧版直接升级**：1.2.1 和 1.2.0 可通过“检查更新”直接升级；首次启动会从同一签名包补齐其他发行文件，完成后再开始监听游戏。

已有 1.2 或 1.2.1 的用户，点“检查更新”并选择“是”即可升级。首次使用请下载 `Civ6_2K_Online_Fix_1.2.2.zip`，解压到新文件夹运行。

沿用 1.2.1 的游戏自动适配和已验证的 DX11、DX12 修复功能。
