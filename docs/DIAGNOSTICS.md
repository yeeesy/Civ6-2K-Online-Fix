# 脱敏诊断与超时反馈

本文描述 `1.1.0` 中的 `diagnostic-v2` 报告。旧版 `1.0.0` 仍提供简要摘要；报告首部的“诊断格式”可用来区分新旧报告。诊断格式号不是产品版本号。

## 怎样提供有效反馈

1. 工具显示最终结果后、关闭窗口前，点击“复制脱敏诊断”，完整粘贴到 Issue 或反馈消息中。监控过程中复制的是当时快照；结束后请再复制一次。
2. 补充游戏内实际显示在线还是离线、是否已经到主菜单、能否进入联机，以及问题是每次发生还是偶发。
3. 补充 Windows 版本、实际 DX11/DX12、工具是否先进入监听、是否使用 Mod。报告中的渲染器是实际检测值，不是 Steam 按钮选择值。
4. 若之前已经做过缓存操作，只提供操作类型、准确文件名、脱敏后的相对位置，以及已有的操作前后报告。不要为采集报告删除数据库，也不要上传 SQLite 文件、账号数据、存档或原始日志。

报告不会自动上传。原始 JSONL、`--diagnose` 输出和截图不等同于脱敏报告；其中可能有路径、PID、地址等信息。`--diagnose` 是安装发现/预检，不会重放完整监控过程，不能代替超时后的报告。

## 报告可以回答什么

- **结果与阶段**：固定结果码、最后活动阶段、各阶段耗时、等待与监控上限。
- **安全检查**：运行时校验和 Guard 安装的类型化结果及已采集的 Win32 错误码；安装前锁向量是否存在、可读时的锁计数。不会输出 owner 线程 ID。
- **介入时机**：安装保护时进程年龄的系统时钟估算值；它有助于比较启动时序，但不能证明保护安装在异常之前。
- **三个独立字段**：计数器、Discovery、SSO 各自的末次读取质量、成功/对象未创建/失败次数、最近一次有效值及其相对快照的时间差。
- **变化过程**：首次观察到拦截的时间、最大采样间隔、状态和读取质量变化的时间线。

所有时间都是相对时长，不输出用户的实际启动日期或绝对时间。时间线最多 32 项：最初 4 项加最近 28 项，中间省略量明确标注；相同采样不重复列出。统计涵盖全部采样。运行中的 UI 快照会节流发布，终态会发布完整的最后快照。

“最近有效值”是历史观察，不表示该字段在结束时仍可读；“末次可读”也只描述那次采样，不保证之后一直有效。三个字段为顺序读取，不是游戏进程的原子快照。

## 超时分类速查

这些分类只针对 `MonitorTimedOutHookKept`，按末次观测依次判断，不是根因结论。

| 分类码 | 已观察到的情况 | 优先查看 |
| --- | --- | --- |
| T0-NO-SAMPLE | 没有监控样本 | 最后阶段、安装结果与耗时 |
| T1-COUNTER-UNREADABLE | 拦截计数器末次不可读 | 错误码、读取失败次数、游戏是否仍运行；不能当作拦截为 0 |
| T2-STATE-UNREADABLE | Discovery 或 SSO 读取失败 | 指针读取还是数值读取失败、最近有效值与时间差 |
| T3-OBJECT-NOT-CREATED | 某服务对象末次指针为空 | 是否一直未创建、启动时机、主菜单状态 |
| T4-INTERCEPTED-NOT-READY | 观察到拦截，但没有确认同时就绪 | 拦截前后的状态变化、哪项没有到 4 |
| T5-NO-INTERCEPTION-NOT-READY | 未观察到拦截，也未确认同时就绪 | 安装时机、状态是否变化、游戏实际状态与已有缓存操作对比 |

只有数值 `4` 按当前已验证的就绪标志处理。其他数值保留原样；没有足够证据把 `2` 等数值解释成网络、数据库或某个固定初始化阶段。零拦截只说明保护启用后的观察，不能排除之前发生过异常。

工具没有检查网络连通性、服务器、账号或 SQLite 内容。即使两份报告显示“删除某文件后成功”，也仍需区分缓存、启动时序和其他条件变化，不能据此直接认定数据库损坏。超时不是数据库删除建议，也不等于游戏一定离线。

## 隐私设计

共享输出从结构化数字、枚举和固定文案生成，不从原始日志做字符串替换。不会输出本机路径、用户名、PID、内存地址、Profile 任意字符串、账号标识、数据库内容或原始异常文本。报告保留工具版本、渲染器、支持等级、相对时长和错误码，这是定位问题需要的非身份信息。

Win32 错误码为 `0` 表示该字段没有记录非零错误，不应脱离阶段和读取质量单独理解为“全部检查通过”。历史错误数即使后来恢复也不会清零。

## 安全行为不变

报告不会触发额外写入或自动修复缓存。超时停止高频监控，但保留本局 Guard 到游戏退出。用户主动停止时仍只恢复本会话拥有的 IAT，可能已执行的远程代码不会热释放。未知构建、身份或必要读取不确定时失败关闭。
