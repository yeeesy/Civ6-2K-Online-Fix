# Civ6 2K Online Fix 1.2

- **适配游戏更新**：支持 Windows Steam 版《文明 VI》1.0.12.72 的 DX11、DX12，保留对 1.0.12.68 的支持。感谢 [TUcookie](https://github.com/yeeesy/Civ6-2K-Online-Fix/pull/2) 提供适配配置。
- **完整反馈文件**：点“反馈问题”即可打开本次诊断 TXT。报告记录启动阶段、状态变化、拦截次数和最终结果，可以直接发文件。以前的报告可从“报告文件夹”找到。
- **一键更新**：发现新的工具版本时，选择“是”即可自动下载并安装；已有配置和反馈文件保留。
- **界面与操作**：精简主窗口提示，改进取消启动、停止监测和重新检测的反馈。

首次使用或从 1.1 升级，请下载 `Civ6_2K_Online_Fix_1.2.0.zip`，解压到新文件夹运行。安装 1.2 后即可在工具内接收后续正式版更新。
